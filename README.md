# E-könyv összefoglaló

Egyetlen HTML-fájlból álló böngészős alkalmazás: PDF / EPUB / TXT feltöltés, fejezetfelismerés, fejezetenkénti AI-összefoglaló és spoiler-elemzés („Ki a gyilkos? / Fordulat”).

Élő oldal: https://zsirafmix.github.io/ekonyv-osszefoglalo/

AI módok: API kulcsos (OpenAI, Groq, OpenRouter, Gemini, Mistral, Cerebras, Hugging Face, LM Studio, Ollama), Chrome beépített AI, Transformers.js, WebLLM, Pollinations (kulcs nélkül), Puter.js, KeylessAI.

Minden feldolgozás a böngészőben történik; a szöveg csak a kiválasztott AI-szolgáltatóhoz kerül.
